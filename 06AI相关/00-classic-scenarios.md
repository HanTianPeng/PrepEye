## 面试官视角：六个场景考察什么

### 场景 1：智能问答 RAG——考察「基础扎实度」

> 面试官心里想：「RAG 是最基础的 Agent 应用。如果连这个都讲不清楚，后面不用问了。」

**必问知识点**：
- Chunk 策略（固定大小 vs 语义分割 vs 递归分割）
- Embedding 选型（OpenAI vs 本地模型，维度影响）
- 检索策略（Top-K、MMR、Hybrid Search）
- Prompt 模板设计（如何让模型基于检索结果回答）
- 评估方法（Hit Rate、MRR、Faithfulness）

### 场景 2：代码助手——考察「Agent 循环理解」

> 「你有用过 Claude Code 或者 Cursor 吗？能讲讲它的原理吗？」

**必问知识点**：
- ReAct 循环：Reason→Act→Observe→Reason
- 工具系统：如何定义工具、如何让模型选择工具
- 上下文管理：token 窗口限制怎么办（压缩/摘要/滑动窗口）
- 安全：代码执行怎么防 rm -rf /

### 场景 3：自主客服——考察「工程化能力」

> 「你们公司的客服系统怎么保证 7×24 小时不出错？」

**必问知识点**：
- 意图识别 + 槽位填充（传统 NLP vs LLM）
- 多轮对话状态管理（Dialog State Tracking）
- 人机协作（什么时候转人工）
- 知识库维护（怎么保证答案的时效性）

### 场景 4：数据分析 Agent——考察「工具编排」

> 「用户说'分析一下上个月的销售趋势'，Agent 具体怎么做？」

**必问知识点**：
- NL2SQL（自然语言转 SQL 的 prompt 设计）
- 工具链编排（查数据库→清洗→画图→解读）
- 安全：SQL 注入防护、数据权限隔离
- 可视化：如何让 Agent 选择合适的图表类型

### 场景 5：办公自动化——考察「系统集成」

> 「Agent 怎么操作 Word 文档？怎么发邮件？」

**必问知识点**：
- 文档处理（python-docx/openpyxl/pypdf）
- 邮件协议（IMAP/SMTP）
- 定时任务（Cron 表达式、任务持久化）
- 权限和安全（Agent 能访问哪些文件/邮箱）

### 场景 6：多 Agent 协作——考察「架构设计」

> 「如果有 10 个 Agent 同时工作，你怎么设计？」

**必问知识点**：
- 编排模式（Sequential/Parallel/Routing/Loop）
- Agent 间通信（消息传递 vs 共享内存 vs MCP）
- 任务分解和结果汇总
- 失败处理和重试策略

## 面试高频交叉题

这些题横跨多个场景，面试官爱问：

1. **「RAG 和 Fine-tuning 的区别？什么时候用哪个？」** → 场景 1 + 2
2. **「Agent 的工具调用失败了怎么办？」** → 场景 2 + 4 + 6
3. **「上下文窗口不够了怎么处理？」** → 场景 1 + 2 + 3
4. **「怎么评估 Agent 的质量？」** → 全部场景
5. **「Agent 的安全怎么保证？」** → 场景 2 + 5
6. **「从零搭建一个 Agent 系统，你会怎么做？」** → 综合
